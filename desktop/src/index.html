外观与版本

发送前翻译

在 Discord 输入框里按 Alt + Enter，把你要说的话翻成目标语言并替换输入框内容， 不会自动发出去（除非你打开下面的开关）。

Discord 图标

默认情况下，直接双击 Discord 图标启动的客户端没有调试端口，翻译不会工作。接管后会由本程序转发启动， 点原来的图标即可正常翻译。
